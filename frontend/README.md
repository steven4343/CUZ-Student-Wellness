# CUZ Student Wellness - Mental Health & Counselling Web App

A mental health and counselling support platform for **Cavendish University Zambia (CUZ)** students, built with React, Vite, and Tailwind CSS.

## System Functionalities

### 1. Anonymous Counselling Chat
- Confidential, anonymous chat with professional counsellors
- Stigma-free support environment
- Real-time messaging interface

### 2. Appointment Scheduling
- Online booking for counselling sessions
- Flexible time selection
- Instant confirmation

### 3. Self-Help Resource Library
- Curated articles on mental health topics (exam stress, anxiety, etc.)
- Guided mindfulness meditation videos
- Interactive wellness assessments
- Crisis help resources

### 4. Performance & Well-being Tracking
- Monitor academic progress alongside mental health metrics
- Data-driven insights for better student outcomes
- Track well-being over time

### 5. 24/7 Accessibility
- Round-the-clock access to resources and support
- Mobile-responsive design for access anywhere
- Emergency support line

### 6. Confidential & Secure
- 100% confidential communication
- Secure platform with privacy safeguards
- Safe space for students to seek help

## Tech Stack

- **Framework:** React 18 + TypeScript
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS 4 + Emotion (MUI)
- **UI Components:** shadcn/ui (Radix primitives) + MUI
- **Animation:** Motion (Framer Motion)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
